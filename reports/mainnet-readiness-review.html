Resolved in source

Transaction binding

Exact wallet, fee payer, signer set, mint, token account, amount, slippage, program, message, and provider-signature checks were added across RPC, payments, Jupiter, RWA, Flash, payroll, offline, and MagicBlock paths.

AI authorization

The public client secret was removed. The API now issues five-minute wallet/device/network-bound sessions; the AI Worker verifies them before credits or provider calls.

Idempotency and recovery

Wallet/network-scoped state, execution locks, persisted recurring-operation identities, verified reconciliation, and retry-safe receipts reduce duplicate submissions and crash races.

Real provider paths

Normal and recurring swaps use Jupiter; RWA catalog/price/trade uses official xStocks intersected with Jupiter; perps use Flash V2; Umbra uses configured mainnet indexer/relayer. Mock analytics and fabricated Flash tools were removed.

AI feature coverage

The agent can prepare confirmed actions for normal/recurring swaps, RWA, funded-ledger Flash trading, Umbra vault operations, and freshly revalidated Umbra claims. Device signing remains mandatory.

Fail-closed capabilities

Unsafe custom RWA mainnet routing, Flash funding/withdrawal, privacy swaps, and Trigger writes are unavailable instead of silently falling back to mocks or unverified transactions.

Important deployed/source mismatch

Do not treat the current deployed capability response as launch truth. The old deployment still reports privacy swaps and Trigger orders as available and contains obsolete custom-RWA mainnet capability text. The reviewed source disables those paths and labels /health as core bootstrap only, with /api/capabilities as the feature gate.
